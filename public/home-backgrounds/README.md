Add the photos you want to use as the home page background to this folder.

Supported formats: .avif, .jpg, .jpeg, .png, and .webp.

The home page discovers image files in this folder automatically and chooses a
random photo each time it is opened. It avoids showing the same photo twice in
a row in the same browser session. With no photos in the folder, the page uses
its built-in gradient background.

Photos are scaled to fill the hero without stretching; depending on the screen
shape, the outer edges may be cropped.
